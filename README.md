# Back-End — UNIPAR 2026

Repositório acadêmico que reúne exercícios, exemplos e projetos desenvolvidos durante os estudos de back-end no curso de Análise e Desenvolvimento de Sistemas.

## Conteúdo

- `Trabalho1bi/` — trabalho acadêmico do primeiro bimestre
- `demo/` — projeto de demonstração e estudos
- `mavenproject1/` — exercícios com Maven
- `minhaAPI/` — estudos de desenvolvimento de API
- `viaCEP/` — projeto Java para consumo da API ViaCEP

## Tecnologias e conceitos

- Java
- Maven
- Programação Orientada a Objetos
- APIs HTTP/REST
- Integração com serviços externos
- Organização de projetos back-end

## Projeto ViaCEP

O projeto `viaCEP` realiza uma consulta de endereço a partir de um CEP informado pelo usuário. Uma versão independente e organizada também está disponível no repositório `ViaCep`.

## Contexto

Este repositório acompanha a evolução dos estudos de back-end ao longo da graduação, reunindo exercícios e projetos desenvolvidos em diferentes etapas da disciplina.

> Arquivos gerados por IDEs, builds e dependências locais não devem ser versionados em novos projetos adicionados ao repositório.
